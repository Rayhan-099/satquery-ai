# Design System (SatQuery AI)

This design system is strictly governed by `AWESOMEDESIGN.md` located at the project root.

## Core Philosophy
SatQuery AI is a professional, high-performance geospatial analysis tool, not a generic SaaS or a crypto dashboard. Its design must exude technical precision, clarity, and authority.

## Color Palette
- **Primary Base:** Deep, restrained slates and muted technical grays. 
- **Accents:** Reserved strictly for indicating state, evidence, or confidence (e.g., precise vegetation greens, water blues, error reds).
- **Prohibited:** Neon colors, rainbow palettes, basic pastels.

## Typography
- **Hierarchy First:** Use typography to guide the user's eye through complex scientific data.
- **Font Selection:** Use technical, crisp sans-serifs suited for dense data interfaces (e.g., Roboto Mono for data, appropriate robust sans-serif for UI). Do not default to Inter, Geist, or Space Grotesk without deliberate intent.

## Layout & Components
- **Whitespace:** Intentional whitespace to separate dense analytical panels.
- **Panels & Cards:** Avoid excessive rounded corners (pill shapes). Use sharp or slightly rounded corners that feel like a professional IDE or GIS software.
- **Loading States:** Use structural skeleton loaders matching the content layout. No solitary spinners for major asynchronous actions.

## Icons
- **No Lucide Icons:** We do not use Lucide. Icons must be bespoke or from a curated set that looks technical and precise.

## Verification Gate
Before a UI component is approved:
1. Apply this design system.
2. Apply the **Taste Skill** (design-taste-frontend).
3. Apply the **Vercel Web Interface Guidelines**.
4. Check against `AWESOMEDESIGN.md` prohibitions.
