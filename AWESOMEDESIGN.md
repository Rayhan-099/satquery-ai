# AWESOMEDESIGN.md (SatQuery AI Design Constitution)

The following rules are NON-NEGOTIABLE unless explicitly changed by the project owner.

## Visual Prohibitions
**DO NOT use:**
- harsh gradients
- rainbow coloring
- neon colors
- basic pastel color palettes
- pure white backgrounds
- purple-and-black color schemes
- liquid glass / excessive glassmorphism
- drop shadows
- radial orb backgrounds
- dot-grid backgrounds
- sparkle icons
- animated arrows
- bento grids
- terminal-window UI as a decorative design pattern
- colored left-side strips
- feature-card rows
- fake testimonials
- checkmark bullet lists
- soft/pill-shaped corner radii everywhere
- excessive rounded cards
- generic AI-dashboard styling

## Typography
- **DO NOT default to:** Inter, Geist, Space Grotesk.
- Choose typography intentionally based on the visual direction.
- Typography should create hierarchy rather than relying on oversized headings everywhere.

## Icons
- **DO NOT use Lucide icons.**
- Use a deliberate icon system or appropriate existing project assets.
- Do not replace every textual concept with an icon.

## Motion
- Motion should be purposeful.
- **Avoid:** constant animations, distracting background movement, animated arrows, gratuitous hover effects, excessive parallax.
- Respect prefers-reduced-motion.

## Loading States
- Every meaningful asynchronous interface must have proper skeleton loading states.
- Do not rely exclusively on spinners.
- Skeletons should match the shape and hierarchy of the eventual content.

## Layout
- Avoid generic collections of cards.
- Prefer strong hierarchy, intentional whitespace, meaningful composition, and layouts that fit the actual SatQuery workflow.
- The UI should feel like a professional geospatial analysis application, not a generic SaaS template.

## Color
- Use a restrained, professional palette.
- Color should communicate: state, evidence, confidence, modality, interaction.
- Do not use color merely for decoration.
- Avoid neon and rainbow palettes.

## Content & Copywriting
- Do not use fake testimonials, statistics, customer logos, or meaningless marketing claims.
- Never use the construction: "It's not X, it's Y."
- Avoid generic AI marketing language. Use precise language describing what SatQuery actually does.

## Product-Specific Design Direction
- **Should visually communicate:** satellite imagery, geospatial analysis, scientific evidence, spatial reasoning, professional tooling, modern technical software.
- **Should NOT look like:** a crypto dashboard, generic AI chatbot, gaming UI, glassmorphism SaaS template, developer terminal, generic analytics dashboard.
